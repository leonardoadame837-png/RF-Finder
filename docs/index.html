What the platform does

A focused pipeline for lawful spectrum observation and repeatable testing.

FFT

Spectrum analysis

Transforms complex IQ samples into a measurable power spectrum with configurable sample rate, center frequency, and FFT size.

SNR

Candidate detection

Estimates a noise floor and identifies spectral regions above the configured detection threshold, including bandwidth and signal-to-noise metrics.

SQLite

Field evidence

Stores observations and investigation records locally so measurements can be reviewed, correlated, and exported later.

Architecture

The RF engine stays independent from the assistant, authentication, database, and UI layers.

Built for trustworthy testing

Deterministic development

The simulator lets CI and local development exercise the RF pipeline without an SDR, antenna, microphone, or cloud API.

Authentication boundary

Local accounts and process-local sessions protect RF operations. Assistant commands must pass an explicit tool and permission boundary.

Hardware-ready design

A source abstraction leaves room for receive-only SDR adapters without coupling hardware drivers to the analyzer or detector.

Run RF Finder

Python 3.11+ is the primary development target.

git clone https://github.com/leonardoadame837-png/RF-Finder.git cd RF-Finder python -m venv .venv .venv\\Scripts\\activate python -m pip install --upgrade pip pip install -r requirements.txt python app/main.py

Run the complete test suite with python -m pytest -q. The GitHub Actions matrix validates Python 3.11 and 3.12.

Lawful-use boundary. RF Finder is intended for passive spectrum analysis and authorized measurement. Do not use it to intercept private communications, decrypt protected traffic, identify private individuals, jam/interfere with RF systems, or conduct unauthorized surveillance.
